# 多语言（i18n）实现与术语表

## 1. 支持语种

| 代码 | 语种 | 说明 |
| --- | --- | --- |
| `zh-CN` | 简体中文 | 原文即 key，不需要单独目录 |
| `zh-TW` | 繁體中文 | |
| `en` | English | 系统语言不支持时的回落语言 |
| `ja` | 日本語 | |
| `es` | Español | |

默认跟随系统语言（`navigator.languages`，Rust 侧读系统 UI 语言）；
系统语言不在上表时回落 `en`。设置页提供「跟随系统 / 简体中文 / 繁體中文 /
English / 日本語 / Español」六选一，选择写入 `localStorage["shellora.locale"]`
并同步到 Rust（`set_locale`），以便托盘菜单与提示同步切换。

## 2. 代码约定

- 文案统一走 `src/i18n/index.ts` 的 `tr(key, vars?)`；
- **key 就是简体中文原文**（gettext 风格），避免另造键名与译文脱节；
- JSX 文本：`<span>{tr("新建连接")}</span>`；
- 属性：`title={tr("关闭")}`，不要写 `title="关闭"`；
- 带变量：`` tr("已连接 {who}", { who: "alice@host" }) ``，占位符用 `{name}`；
- 复数/数量：中文原文里用 `{n}`，各语种自行处理单复数；
- 协议名与品牌名保留原文（见白名单）：SSH / SFTP / PTY / Shellora /
  OpenSSH / Ed25519 / One Dark 等；
- `scripts/check-i18n.mjs` 会扫出所有未包进 `tr()` 的中文、目录缺键、
  以及 en/es 里残留的汉字，CI 里失败即阻断。

## 4. 刻意保留原文的字符串

| 字符串 | 理由 |
| --- | --- |
| SSH / SFTP / PTY | 协议缩写，各语种通用，翻译反而增加理解成本 |
| Shellora | 产品名 |
| OpenSSH / Ed25519 / RSA / ECDSA / AES / HMAC | 算法与实现名 |
| One Dark / One Light | 终端配色方案专名 |
| MiB/s、KiB/s | 国际单位写法 |
| SHA256 | 算法名 |
| Windows / macOS / Linux | 平台名 |

## 5. 布局适配

- 会话标签最大宽度 260px，超出省略，不换行；
- 工具栏按钮使用 `flex: none` + `white-space: nowrap`，西语/日语变长时
  由同排的弹性区域收缩，不允许把按钮压成两行；
- 设置页标签列固定 150px，说明文字可换行；
- 五种语言截图见 `design/v2/shots-i18n/`。

### 5.1 实测调整（1.1.0）

| 问题 | 现象 | 处理 |
|---|---|---|
| 窄抽屉（340px）文件面板头部 | 西语「Actualizar cola」、日语「ターミナル」被截断 | 窄抽屉下按钮只留图标，文案进 `title`/`aria-label` |
| 传输队列表头 | 「Cola de transferencia」折成两行 | 标题 `white-space: nowrap`，计数在窄抽屉隐藏 |
| 队列行方向标签 | 「LOCAL → REMOTE」「ローカル → リモート」挤掉状态 | 窄抽屉隐藏方向标签（左侧箭头已表达方向） |
| 运行时状态 | 英文「Transferring」被截成「Transferri…」 | 英文改 `Active`、西语改 `Activo` |
| 面板模式 | 西语把「挤压」误译为 `Sobrescribir`（与“覆盖文件”撞词） | 改用独立的 `挤压中/覆盖中` 键，西语为 `Desplazar/Superponer` |

## 6. 验证

### 6.1 未翻译扫描

`node scripts/check-i18n.mjs`（纳入 CI）实际输出：

```text
tr() 键：357 条；扫描文件：25 个
未翻译中文：0 条
目录缺键：0 条
英文/西语残留汉字：0 条
```

扫描规则：逐行遮罩 `tr("…")` 后剩余的汉字即未翻译；同时校验四份目录的 key 完整性、
占位符集合一致（`{name}`/`{n}` 等），以及 en/es 的**值**里不得出现汉字
（key 本身是中文原文，不参与该判定）。`console.*` 日志、单测文件、无头预览夹具不计入。

### 6.2 刻意保留原文

除第 4 节列出的协议名/算法名/产品名，另有几处固定视觉标签不随语言变化：
状态栏主题徽标 `LIGHT` / `DARK`（全大写设计元素，与品牌色块绑定）、
`SFTP`、`SSH`、`ETA` 已改为本地化文案（`剩余 {eta}` 等），不再保留英文缩写。
