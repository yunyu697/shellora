## 一、结论

全应用共查出 **22 项**度量偏差（同类已合并），修复 **17 项**，判定「保持现状」**5 项**。其中左栏 9 项、文件/队列 4 项、设置/连接页 2 项、全局控件（顶栏/滚动条）2 项。

核心问题是**左栏自身没有内边距，导致三套左缘**：面板内缘 13、分组标题文字 15、行图标 26；标题、分段控件、搜索框全部贴边。修后统一为 12px 内边距，所有内容左缘 25。

## 四、保持现状的判定理由

1. **折叠态没有 52px 图标栏**：v2 壳层自 1.1.x 起将会话库改为浮层，`railCollapsed` 的语义是「收起浮层」，`shellbody` 为 `display:block`，52px 首列与 `mini-*` 样式自那时起就不再生效。**这是设计迁移后的现状，不是本次新引入的回归**。若需要恢复图标态，应作为独立设计需求，而不是在度量整改里顺手改。已在截图中标注说明。
2. **设置页勾选框 13×13**：`label` 包住输入框，整行 285×40 均可点击，实际命中区达标；放大到 28 会破坏表单密度。
3. **滚动条 15px 占位**：`scrollbar-gutter: stable` 会让无滚动时也永久空出 15px，使行高亮右侧多出一条空白，与「左右留白对称」冲突；保留原生 auto 行为。
4. **1px 光学差**：文字块（15+2+13 行盒）中心比 30px 图标中心高 1px，来源是字体 ascent/descent，非布局错误；强制 +1px 会引入伪对齐。
5. **顶栏 12.5/13 字号**：标签与按钮的字号层级差，非同类元素。

## 五、固化到 CI 的规则

新增 `scripts/check-ui-metrics.mjs`（`pnpm lint:metrics`，已接入 `.github/workflows/ci.yml`），静态解析 `base.css`，失败即中断 CI：

1. 命中区：`.rail-head .add`、`.srow__x`、`.qrow2 .qa`、`.qhead2 .qb`、`.dop`、`.sb-toggle`、`.topbar .iconbtn`、`.crumb2 .cb` 宽高/最小宽高 ≥28；`.seg` 用「容器高 − 上下内边距」推导按钮高 ≥28；`.conntop .back` 最小高 ≥28。
2. 行高单源：`.frow` 的 CSS 高度必须等于 `FilePane.tsx` 的 `ROW_H`。
3. 栅格一致：表头与文件行 `grid-template-columns` 完全相同；`.frow .sz/.dt` 禁止写死宽度（含旧规则）。
4. 左栏节奏：`.rail` 上下 12、`.rail-head`/`.glabel`/`.rail-foot` 左右 12、`.seg`/`.railsearch` 左右外边距 12。
5. 同名唯一：`.sbtab`、`.sb-toggle`、`.dops`、`.dop` 只允许一处定义，避免旧值覆盖新值。
6. 面板左缘：队列头与队列行一致；抽屉头/操作行与文件行一致。
