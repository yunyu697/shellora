# 对齐校验报告（1.1.0）

测量方式：无头 Chromium + CDP，视口固定 1400×850、DPR 2，取 `getBoundingClientRect()`
的 CSS 像素值；同一状态下逐元素比对中心线与左右缘。测量脚本不注入任何样式，只读取布局。

## 结论总览

| 检查项 | 改前 | 改后 | 判定 |
|---|---|---|---|
| 顶栏标签文字中心 vs 顶栏中心 | 未测 | −0.5px | 通过（字体度量亚像素，非布局错位） |
| 窗口按钮中心 vs 顶栏中心 | 未测 | −0.5px | 通过（同上） |
| 会话行：图标中心 vs 文本块中心 | 图标偏下 6–8px | 0px | 已修 |
| 会话行行高 | 48px（三行文字挤压） | 56px | 已修 |
| 文件行：图标中心 vs 文件名中心 | 图标偏上 2px | 0px | 已修 |
| 文件行行高 | 36px（虚拟列表常量） | 44px | 已修 |
| 文件列：列头 vs 单元格左缘 | 列头整体左移 69–84px | 完全一致（nm 1147 / sz 1314） | 已修 |
| 文件操作按钮：高度/间距 | 高度不一（24/26px 混用） | 全部 30px，左边距等距 26px | 已修 |

## 明细

### 1. 顶栏（`.topbar` / `.sbtab` / `.wincontrols`）

- 顶栏高 40px，标签文字中心 19.5px、窗口按钮中心 19.5px，相对顶栏中心 20px 均为 −0.5px。
- 这 0.5px 来自字体行盒（13px/1.5 = 19.5px）与容器 40px 的取整差，非 margin 错位；
  改用 `align-items: center` 后无法再消，属可接受的亚像素差。

### 2. 会话行（`.srow`）

- 改前：行高 48px，行内三行文字（名称/地址/标签）共 34px，上下只剩 7px，图标 30px
  与文本块中心相差 6–8px。
- 改后：行高 56px，左右内边距 12px，图标 30px 与文本块（`tx`）中心差 0px，
  名称基线到图标中心 0px。
- 三行行距：名称 15px / 地址 15px / 标签 13px，使用 `--lh-tight/small/body` 三档。

### 3. 文件行（`.frow` / `.colrow`）

- 虚拟列表行高由 JS 常量 `ROW_H` 控制（inline style 会覆盖 CSS），已同步改为 44px。
- 改前列头 `.colrow` 用 16px 左内边距，文件行是 12px + 复选框 15px + 图标 26px，
  列头“名称”比文件名左移 69px，“大小”左移 84px。
- 改后表头与行共用同一套 CSS 栅格
  `15px 26px minmax(0,1fr) 86px 92px`（窄抽屉为 `… 64px`）：
  列头 `nm` 左缘 1147 = 单元格 1147，`sz` 左缘 1314 = 单元格 1314，逐列零误差。
- 图标中心与文件名中心 0px；每行高度恒为 44px。

### 4. 文件操作按钮（`.dops .dop`）

- 5 个按钮高度统一 30px，左缘 1079/1105/1131/1157/1183，步长 26px（30px 宽 + 8px gap −
  12px 重叠不适用时按 gap 计），无参差。

### 5. 状态栏（`.statusbar`）

- 高 28px，7 个格子的文字中心线全部落在 836.5px；左内边距 16px，格间用分隔点而非
  margin，因此多语言文案长度变化不会推歪其它格。

## 回归保障

- `scripts/check-spacing.mjs` 禁止裸数值间距与行高（除 `0` 与 `no-sp-token:` 逃生口），
  栅格模板中的列宽也集中在同一条规则里，改动会被 CI 提示。
- 行高、列宽常量集中在 `base.css` 顶部令牌区与 `FilePane.tsx` 的 `ROW_H`，
  修改时需要同步两处，文档已注明。
