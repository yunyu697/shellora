# 间距体系与疏密规范

> 适用范围：`src/styles/base.css` 以及所有 React 内联样式。
> 守卫脚本：`scripts/check-spacing.mjs`（CI 中 `pnpm lint:spacing`）。改样式前先读这一页。

## 1. 令牌档位

只有八个间距档位，组件不得再写裸 px：

| 令牌 | 值 | 用途 |
| --- | ---: | --- |
| `--sp-0` | 2px | 光学微调：图标与文字贴合、相邻小标签 |
| `--sp-1` | 4px | 紧凑控件内部间距 |
| `--sp-2` | 8px | 控件之间、图标与文字 |
| `--sp-3` | 12px | 行内左右留白、面板边界 |
| `--sp-4` | 16px | 工具栏与内容、卡片内边距 |
| `--sp-5` | 24px | 区块之间 |
| `--sp-6` | 32px | 大区块、页面级留白 |
| `--sp-7` | 48px | 空状态与引导区 |

行高只有三档：`--lh-tight` 13 / `--lh-small` 15 / `--lh-body` 20；其余使用无单位倍数。

平台常量（例如 macOS 红绿灯让位的 78px）无法落进档位时，在声明行尾写
`/* no-sp-token: 理由 */`，脚本会放行并保留理由。

## 2. 改造前的现状（2026-11-14 审计）

`node scripts/spacing-audit.mjs` 在改造前的结果：

- CSS 间距声明 355 条，其中裸值 346 条、已是令牌 9 条；
- 内联样式 5 处；
- 裸值共 55 种组合，最密集的是 8px（49 次）、10px（35 次）、6px（28 次）、
  5px（22 次）、9px（16 次）、7px（14 次）——同一屏里出现 5/6/7/9/10 五套近似值，
  视觉上自然显得碎而挤。

## 3. 收敛映射

按「就近档位、略偏宽松」的原则一次性收敛：

| 原值 | 收敛到 | 说明 |
| --- | --- | --- |
| 1 / 2px | `--sp-0` | 光学微调 |
| 3 / 4 / 5px | `--sp-1` | 原 5px 收 4px，避免半像素感 |
| 6 / 7 / 8 / 9px | `--sp-2` | 原 6/7/9 统一 8px，增加呼吸 |
| 10 / 11 / 12 / 13px | `--sp-3` | 原 10px 提到 12px |
| 14 / 15 / 16 / 18px | `--sp-4` | |
| 20 / 22 / 24 / 26px | `--sp-5` | 原 20/22 提到 24px |
| 30 / 32px | `--sp-6` | |
| 47px | `--sp-7` | |
| 负数 | `calc(var(--sp-N) * -1)` | 负外边距显式表达 |

结果：CSS 间距声明 354 条中裸值只剩 34 个 `0`（合法），内联样式 0 处裸值。

## 5. 对齐校验

见 `design/v2/shots-spacing/align-report.json`：用 CDP 量取同一列内元素的
`getBoundingClientRect()`，检查文字基线、图标中心与按钮左右缘。结论写在
`docs/design/spacing-align.md`。

## 6. 防回归

- `pnpm lint:spacing`：扫裸 px、扫未定义令牌、扫不在档位的令牌值、扫内联样式裸值；
- CI 在 `pnpm tsc --noEmit` 之后执行，失败即阻断合并；
- 新增间距先查上表，没有合适档位时先讨论是否扩展档位，不要直接写 px。
