# Shellora 界面重做 · v2 两套方案对照

> 结论：**采用方案一（终端优先、文件按需）**，文件面板宽度可拖可记。方案二保留作对照，不再推进。
> 原型：`concept-a-terminal-first.html`、`concept-b-single-surface.html`（单文件，双击用浏览器打开即可操作，无外部依赖）。

## 旧设计为什么不好用

顶栏 64px + 常驻会话栏 248px + 状态栏 32px = **344px 的固定 chrome**，在 1440 宽下只剩约 1096px 横向空间；终端与文件还要并排对半分，各自只有约 550px——日志一行就被折断，文件列表连"修改时间"都放不下。信息看起来很齐全，但长时间使用时的实际可用面积被切碎了。

## 两套方案对照

| | 方案一 · 终端优先，文件按需 | 方案二 · 单一视区，模式切换 |
| --- | --- | --- |
| 解决什么问题 | 终端是唯一的主视区，永远全宽；文件能力按需以抽屉呼出（挤压 / 覆盖两种形态），收起即恢复全宽 | 同一时间只做一件事：一个全宽工作区在"终端"与"文件"之间切换，彻底没有并排 |
| 牺牲什么 | 需要一次"呼出"动作才能看目录（Ctrl+Shift+E）；挤压态下终端会被压窄 | 看目录时看不到终端输出，反之亦然；依赖状态保留来抵消来回切的成本 |
| 适合什么使用习惯 | 大部分时间在终端里敲命令，偶尔查目录、传文件、把路径拖进命令 | 习惯"专注做一件事"、频繁在两个视图间来回核对（改完文件立刻跑命令） |
| chrome 厚度 | 36 + 34 + 22 = **92px** | 38 + 32 + 20 + 26（可折叠传输条）= **90px** |
| 与旧设计的关键差异 | 去掉 248px 常驻会话栏（改为 34px 横向会话标签）；顶栏 64→36；状态栏 32→22；不再有并排分栏 | 同样砍掉常驻会话栏与厚顶栏，但把"分栏"换成"模式切换 + 状态保留"，用顶栏分段控件代替双栏 |
| 多会话扩展 | 会话标签横排在 34px 条里，切换保留各自面板宽度策略与路径 | 每会话独立保存 cwd / 选中 / 筛选 / 两侧滚动位置，切回不丢；另可把文件视图开成独立窗口 |

## 方案一的宽度规格（已落地到原型）

- 默认 420px（≥1700 宽时 460px）；**最小 340px**（五个操作按钮与文件名不被裁切）、**最大 720px 且不超过窗口 56%**，挤压态终端至少保留 560px。
- 拖分隔条：hover 高亮 + `col-resize`，拖动用 pointer capture + rAF 合并，拖动中不重排抖动、终端滚动位置不动；越界直接夹住。
- **双击分隔条**恢复默认宽度；键盘 `Alt+[` / `Alt+]` 微调 40px（按住 Shift 为 120px），分隔条获得焦点时 `←/→` 与 `Home` 同样可用。
- 宽度写入 `localStorage`：关掉再开、切换会话、重开应用都沿用上次值；窗口变窄时临时夹住但不覆盖已记住的值。
- 收起后终端恢复全宽，无残留空白与分隔线。

## 尺寸表现

| 宽度 | 方案一 | 方案二 |
| --- | --- | --- |
| 1280 | <1360 默认"覆盖"，终端保持全宽；抽屉 380px | 隐藏类型/权限列，搜索框收窄，表格仍完整 |
| 1440 | 默认"挤压"，抽屉 420px，终端 1020px | 全列 + 可选右侧预览面板 |
| 1920 | 默认抽屉 460px，可拖到 720px | 全列 + 预览 + 传输条展开 |
| 最小可用 | **900 × 600** | **880 × 560** |

## 文件操作入口

两套都做完了上传 / 下载 / 重命名 / 新建目录 / 删除，且都能把路径拖进终端：

| 操作 | 方案一 | 方案二 |
| --- | --- | --- |
| 上传 | 面板工具栏「上传」/ 拖文件进面板 / `Alt+U` | 文件视图工具栏「上传」/ 拖入 / `Alt+U` |
| 下载 | 选中后「下载」批量入队，底部传输条看进度 | 工具栏「下载」/ 预览面板里的「下载」 |
| 重命名 | 行内编辑 / `F2` / 右键菜单 | 行内编辑 / `F2` / 预览面板 |
| 新建目录 | 「新建目录」/ `Alt+N` | 「新建目录」/ `Alt+N` |
| 删除 | 「删除」+ 确认 + 撤销 toast / `Delete` | 同左，另有预览面板入口 |
| 拖路径 | 拖到终端插入带引号路径，`Shift` 拖入插入 `cd` | 拖到终端标签上松手即切换并插入路径 |
